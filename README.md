# Djembar Portfolio

A modern fullstack web developer portfolio built with Next.js and Tailwind CSS, ready for Vercel deployment.

## Features
- Dark theme, responsive design
- Home, Projects, Experience, Certifications, Contact sections
- Download CV & Contact buttons
- Tech stack icons, skill cards, project/certification cards
- Contact form

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying to Vercel
- Push your code to GitHub.
- Import your repo to [Vercel](https://vercel.com/).
- Follow Vercel's instructions for Next.js deployment.

## Customization
- Edit `/app/page.tsx` and add your own content.
- Add images, CV, and project details in `/public`.
